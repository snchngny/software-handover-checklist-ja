# 小規模ソフトウェア引継ぎチェックリスト

小規模開発会社が、社員退職や外注離脱の前に、顧客案件で止まる作業と残す資料を確認する無料チェックリストです。

## 使い方

1. [CHECKLIST.md](CHECKLIST.md)をコピー
2. 顧客案件1件ごとに、離脱日と後任責任者を決めて確認
3. 未確認項目は埋めずに「未確認」と記録
4. APIキー、パスワード、個人情報の実値は書かず、保管場所と取得手順だけを記録

この無料版は確認項目の一覧です。受入条件表、確認根拠、利用・障害対応・取消手順の編集用テンプレートと架空の記入例は、有料版に収録しています。

[顧客案件の引継ぎ準備テンプレート5点を見る](https://yukilec.gumroad.com/l/software-handover-docs-ja?utm_source=github&utm_medium=repo&utm_campaign=handover-checklist)
